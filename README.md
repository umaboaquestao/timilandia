# TiMIlandia

Mini-jogo web 2D jogável no navegador, construído com Vite e Canvas.

## Executar localmente

```bash
npm install
npm run dev
```

Abre o endereço indicado pelo Vite no navegador. Usa `WASD` ou as setas para controlar a bicicleta.

## Mecânicas

- Recolhe energia verde e moedas amarelas para aumentar a pontuação.
- Evita as zonas de poluição vermelhas.
- Começas com 3 vidas; ao perder todas aparece o ecrã de Game Over.
- O mapa tem câmara com deslocação, estradas, edifícios futuristas e zonas verdes.
- Completa três missões rápidas para ganhares bónus de pontuação.
- No Game Over podes guardar o teu nome no Top 10 deste dispositivo.
- Em telemóveis, usa os controlos táteis no canto inferior direito.
